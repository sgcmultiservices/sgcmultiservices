# SGC Website

Static website for SGC Printing, Stationery, Disposable Wholesale & Multiservice.

## Preview locally

Open `index.html` in a browser. Keep `services.html` and the `assets` folder beside it.

## Publish with GitHub Pages

This project is ready for GitHub Pages on the free plan. Use a **public** GitHub repository and publish from the `main` branch, repository root (`/`). GitHub Pages will serve `index.html` automatically. The website itself is public.

To turn Pages on after pushing the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will show the public site URL in that Pages settings section.
